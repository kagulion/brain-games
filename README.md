# Игры разума

«Игры разума» — набор из пяти консольных игр, построенных по принципу популярных мобильных приложений для прокачки мозга. Каждая игра задает вопросы, на которые нужно дать правильные ответы. После трех правильных ответов считается, что игра пройдена. Неправильные ответы завершают игру и предлагают пройти ее заново."

## Игры

- **Калькулятор** — `npx brain-calc`  
  Правила: Калькулятор генерирует случайное выражение из двух чисел и одного оператора, правильный ответ — результат выражения.
- **Прогрессия** — `npx brain-progression`  
  Правила: нужно найти пропущенные числа в последовательности чисел.
- **Чет-нечет** — `npx brain-even`  
  Правила: отвечайте «да», если число четное, в противном случае отвечайте «нет».
- **Наибольший общий делитель (НОД)** — `npx brain-gcd`  
  Правила: найти наибольшее целое число двух целых чисел, на которое каждое из данных чисел делится без остатка. Например, для чисел 12 и 18 общими делителями являются 1, 2, 3 и 6. Наибольшим из них является число 6, поэтому НОД(12, 18) = 6.
- **Простое число** — `npx brain-prime`  
  Правила: Игроку показывается число, нужно ответить "да", если оно простое, и "нет" — если нет. Простое число — это натуральное число (целое положительное), которое больше единицы и имеет ровно два различных натуральных делителя: единицу и само себя.
