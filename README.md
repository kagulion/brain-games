# Игры разума

«Игры разума» — набор из пяти консольных игр, построенных по принципу популярных мобильных приложений для прокачки мозга. Каждая игра задает вопросы, на которые нужно дать правильные ответы. После трех правильных ответов считается, что игра пройдена. Неправильные ответы завершают игру и предлагают пройти ее заново."

## Установка

```
git clone https://github.com/kagulion/brain-games.git
cd brain-games
npm install
npm link
```

## Игры

| Команда             | Игра                                | Правила                                                                                                                                                                                                                                          |
| ------------------- | ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `brain-even`        | **Чет-нечет**                       | Отвечайте «да», если число четное, в противном случае отвечайте «нет».                                                                                                                                                                           |
| `brain-calc`        | **Калькулятор**                     | Калькулятор генерирует случайное выражение из двух чисел и одного оператора, правильный ответ — результат выражения.                                                                                                                             |
| `brain-gcd`         | **Наибольший общий делитель (НОД)** | Найти наибольшее целое число двух целых чисел, на которое каждое из данных чисел делится без остатка. Например, для чисел 12 и 18 общими делителями являются 1, 2, 3 и 6. Наибольшим из них является число 6, поэтому НОД(12, 18). = 6.          |
| `brain-progression` | **Прогрессия**                      | Нужно найти пропущенные числа в последовательности чисел.                                                                                                                                                                                        |
| `brain-prime`       | **Простое число**                   | Игроку показывается число, нужно ответить "да", если оно простое, и "нет" — если нет. Простое число — это натуральное число (целое положительное), которое больше единицы и имеет ровно два различных натуральных делителя: единицу и само себя. |

## Зависимости

Библиотека для Node.js, которая позволяет читать ввод от пользователя **синхронно** из командной строки.

### yoctocolors

Маленькая библиотека для добавления цветов тексту в CLI.
